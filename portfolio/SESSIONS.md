## Tips for Future Sessions

1. **Add a row here** before ending every session — even a one-liner beats `NULL`.
2. **Use the Session ID** from the Copilot UI or `/chronicle` — first 8 chars is enough.
3. **Mark agent type**: CLI sessions are quick; Coding Agent sessions commit to git automatically.
4. **Link your outputs**: file paths, PR numbers, or deployed URLs.
5. **Chain sessions**: end a Code Review session → immediately start a Coding Agent session to fix issues.
